FUNCIONALIDADES INCLUIDAS:
Catálogo completo: Renderizado dinámico de tarjetas de películas utilizando map().

Búsqueda en tiempo real: Filtrado por título de película mientras el usuario escribe.

Filtros combinados: Capacidad de filtrar el catálogo por género, franja de años y calificación mínima de forma simultánea utilizando filter().

Detalle de película: Renderizado condicional para visualizar la información completa de una película seleccionada.

Sistema de Favoritos: Agregar, quitar y visualizar una sección exclusiva con las películas guardadas (gestionado por IDs en el estado de React).

Valoración Personalizada: Sistema interactivo para calificar películas de 1 a 5 estrellas.

Barra lateral inteligente: Visualización rápida de películas favoritas, mejor valoradas y estrenos recientes.

INSTRUCCIONES PARA EJECUTAR EL PROYECTO:
Para correr este proyecto en tu entorno local, sigue estos pasos:

Clonar el repositorio:
git clone [ENLACE_DE_TU_REPOSITORIO_AQUI]

Navegar a la carpeta del proyecto:
cd catalogo-peliculas

Instalar las dependencias:
npm install

Iniciar el servidor local de desarrollo:
npm run dev

Abrir en el navegador:
Visita http://localhost:5173/ para ver la aplicación funcionando.
